# Help

## Browsing Resources

Use the [Explorer](https://data-library-browser-85fc677edd07.herokuapp.com/) page to explore available resource types. Click on a resource type to see a paginated list of items.

## Searching and Filtering

You can filter results using query parameters. For example:

- `/explorer/research-briefings?topic=123` - Filter by topic
- `/explorer/research-briefings?publisher=456` - Filter by publisher

## Pagination

Results are paginated. Use the navigation links at the top and bottom of the list to move between pages.

## RSS Feeds

RSS feeds are available for each resource type:

- `/explorer/research-briefings/feed`
- `/explorer/deposited-papers/feed`
