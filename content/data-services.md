## Linked Data 

### SPARQL endpoints

Parliament currently has two linked data stores with SPARQL endpoints:

- [Procedural](https://api.parliament.uk/sparql) - currently covering Statutory Instruments and Treaties. We maintain a library of useful [SPARQL queries](https://ukparliament.github.io/ontologies/procedure/meta/queries/).

We plan to make available a second SPARQL endpoint to expose the data used by the Parliamentary Search application.

### SOLR index

The SOLR search index that supports Parliamentary Search will be made publicly available in due course.

## Other procedural APIs

- [Erskine May](https://erskinemay-api.parliament.uk/index.html) | [OpenAPI specification](https://erskinemay-api.parliament.uk/swagger/v1/swagger.json)
- [Deposited Papers](https://depositedpapers-api.parliament.uk/index.html) | [OpenAPI specification](https://depositedpapers-api.parliament.uk/swagger/v1/swagger.json)
- [Hansard](https://hansard-api.parliament.uk/swagger/ui/index) | [OpenAPI specification](https://hansard-api.parliament.uk/swagger/docs/v1)

As well as the APIs published on Developer Hub, there are additional services:

- [Members Data Platform](https://data.parliament.uk/membersdataplatform/default.aspx) - an alternative API for Member Data with OData and query services.

REST APIs are available for datasets within [data.parliament.uk](https://data.parliament.uk/) along with html, csv and ttl views. These include research briefings from the Commons and Lords Library and Parliamentary Office of Science and Technology.
