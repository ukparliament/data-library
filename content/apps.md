# Tools

The House of Commons Library has developed applications and utilities to support the use of Parliament's information.

- [Election Results](https://electionresults.parliament.uk/) - a website covering parliamentary elections (general and by-elections) from 2010. Data is available as .csv downloads or through [Datasette Lite](https://lite.datasette.io/?url=https%3A%2F%2Fraw.githubusercontent.com%2Fukparliament%2Fpsephology-datasette%2Fmain%2Fpsephology.db%3Fraw%3Dtrue#psephology). The Library also has [a website](https://api.parliament.uk/uk-general-elections) which presents data on elections from 1832 to 2019.
- [Standing Orders](https://api.parliament.uk/standing-orders/) - a website presenting UK Parliament Standing Orders from 1811 (using data from UK House of Commons Standing Orders Dataset, Version 3.0.1, ParlRulesData Project. 2023.)
- A number of apps to produce feeds of UK Parliament data, covering [Committees](https://api.parliament.uk/committees), [Written Questions](https://api.parliament.uk/written-answers/), [Library and POST research briefings](https://api.parliament.uk/library-feeds) and [Bill papers](https://api.parliament.uk/bill-papers).
These applications are used by Library-managed [social media accounts](https://ukparliament.github.io/ontologies/meta/bots/) to publish updates to Bluesky and Mastodon.
- [Parliamentary Time](https://api.parliament.uk/egg-timer) - a resource for parliamentary time. It includes calculators for scrutiny start and end periods, and for the number of sitting days between two periods. Users can subscribe to calendars for future recess dates, sitting and adjournment days.
